# 運動分帳網站

這是一個可直接打開的靜態網站，用來記錄運動場次、參加者、付款人與未付款狀態，並自動計算抵銷後的轉帳結果。

## 使用方式

1. 打開 `index.html`。
2. 在「人員設定」新增常一起運動的人。
3. 在「新增場次」填入日期、時間、項目、總費用、付款人與參加者狀態。
4. 「誰要付錢」會自動更新最後需要轉帳的人、收款人與金額。

資料會存在 Supabase 雲端資料庫裡。若放到公開網址，大家會看到同一份人員、場次、付款狀態與付款流向。

## 分帳規則

- 每場費用平均分給所有參加者。
- 標記「未付款」的人，會欠該場付款人一份費用。
- 若兩個人彼此互欠，系統只顯示抵銷後的差額。
